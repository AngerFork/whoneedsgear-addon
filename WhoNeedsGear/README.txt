Who Needs Gear? addon (v1.1.1, game 12.1.5)
1. Copy the WhoNeedsGear folder into:  World of Warcraft/_retail_/Interface/AddOns/
2. Restart WoW (or /reload).
3. Type /wng export (or left-click the minimap button), press Ctrl+C, and paste into "Addon Import" on whoneedsgear.info.

Commands
  /wng export        Export equipped gear, enchants, gems, upgrade tracks and bag upgrades
  /wng last          Show the last saved export (also saved automatically when you log out)
  /wng upgrades      List upgrades sitting in your bags in chat
  /wng minimap       Show/hide the minimap button (drag it to move)
  /wng remind <days> Reminder on login when an export is older than this (0 = off, default 3)
